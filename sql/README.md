# SQL Analytics

This directory contains SQL queries used for analytical
processing and business insights in the Olist E-Commerce
Data Engineering project.

## Planned SQL Analysis

- Monthly Revenue Analysis
- Monthly Order Analysis
- Top Selling Products
- Seller Performance Analysis
- Order Status Analysis
- Business KPI Analysis
- Data Quality Validation
- Duplicate Record Detection
- Bronze-Silver Data Reconciliation

## Data Source

Analytics queries are executed against processed Delta tables
within the Databricks Lakehouse environment.
